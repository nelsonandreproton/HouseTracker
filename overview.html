HouseTracker

Portuguese property auctions and bank sales — homes in Lisboa and Setúbal up to 300 000 EUR

Python 3.11 FastAPI + SQLite 4 sources Web list + Telegram Docker Compose

1. What this project does

Purpose

Every 6 hours it scrapes Portuguese property auction and bank-sale sites, keeps apartments and houses in the Lisboa and Setúbal districts priced at or below 300 000 EUR, stores them in SQLite, serves a single-page list at / and sends Telegram alerts for new listings.

3. Pipeline

One scrape run (every 6 h, single worker)

Fetch4 sources
→
Filterdistrict, kind, price, no partial ownership
→
SQLite upsertnew / still active
→
Telegramnew listing, broken / recovered

The first successful run seeds silently and sends one "started" summary. More than 10 new listings in a run are sent as one grouped message. Partial-ownership lots (fractions, nua propriedade, usufruto, direito de superfície, meação, quotas) are excluded by title.

4. Health, TLS & deployment

Source health

Brokenfetch raised, or raw total 0 for e-leiloes / Leilosoc only (banks may be legitimately empty) Alertsonly on ok → broken, plus a recovery message Listingsa broken source never deactivates its listings

TLS note

e-leiloes.pt sends an incomplete chain. The Sectigo DV R36 intermediate is committed in certs/ and appended to the certifi bundle for that session only; verification is never disabled. Leaf cert expires 2026-12-20 — update certs/ if the chain changes.
